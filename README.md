# OpenClassrooms — Parcours Développeur Front-End (JavaScript / React) 🌐

Ce méta-répertoire regroupe l'ensemble des projets réalisés dans le cadre du parcours certifiant **Développeur Front-End (JavaScript / React)** chez [OpenClassrooms](https://openclassrooms.com/).

L'intégralité de l'historique Git d'origine de chaque projet a été préservée via `git subtree`.

## 🛠️ Stack technique globale

* **Core** : JavaScript (ES6+), TypeScript, HTML5 sémantique, CSS3 / Sass
* **Frameworks & Libs** : React, React Router, Redux Toolkit
* **Dataviz & UI** : Recharts, composants customisables, accessibilité (ARIA / A11y)
* **Tests & Qualité** : Jest, React Testing Library, ESLint, Prettier
* **Backend & API** : Node.js, Express, MongoDB, Swagger

## 🚀 Utilisation

```bash
# Cloner le méta-répertoire complet
git clone https://github.com/0ddbird/openclassrooms-javascript.git
cd openclassrooms-javascript

# Explorer un projet spécifique (ex: Kasa)
cd p11-kasa
npm install
npm start
```
