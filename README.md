## 🇬🇧 English Version

This meta-repository gathers all projects completed during the **Front-End Developer (JavaScript / React)** certification program at [OpenClassrooms](https://openclassrooms.com/).

The full original Git commit history for each individual project has been preserved using `git subtree`.

### 🛠️ Global Tech Stack

* **Core & Languages**: JavaScript (ES6+), TypeScript, Semantic HTML5, CSS3 / Sass
* **Frameworks & State**: React, React Router, Redux Toolkit
* **Dataviz & UI**: Recharts, accessible UI components, ARIA / A11y guidelines
* **Testing & Quality**: Jest, React Testing Library, ESLint, Prettier
* **Backend & API**: Node.js, Express, MongoDB, Swagger

### 🚀 Getting Started

```bash
# Clone the entire meta-repository
git clone https://github.com/0ddbird/openclassrooms-javascript.git
cd openclassrooms-javascript

# Explore and run a specific project (e.g., Kasa)
cd p11-kasa
npm install
npm start
```
